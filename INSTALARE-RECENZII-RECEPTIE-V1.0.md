# Recenzii Google din Recepție atelier

Pachetul adaugă în fiecare fișă butonul „Solicită recenzie”.

- trimite prin Evolution API un mesaj WhatsApp cu linkul Google;
- cere confirmare înainte de expediere;
- salvează data, ID-ul mesajului și ultima eroare;
- împiedică retrimiterea accidentală în primele cinci minute;
- permite retrimiterea manuală ulterioară.

Migrarea SQL este idempotentă.
